# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities in public GitHub Issues.

Use GitHub's private vulnerability-reporting form:

<https://github.com/LealLab/LealFinance/security/advisories/new>

If the private-reporting form is unavailable, do not disclose sensitive details
in a public issue. Contact a LealLab maintainer through a private channel they
have provided. This repository does not currently publish an alternate private
contact address or a response-time SLA.

When possible, include the affected commit or version, reproduction steps,
impact, and any safe mitigation. Please allow maintainers reasonable time to
investigate before public disclosure.

## Supported versions

The project does not currently publish a formal version-support matrix. Include
the exact commit or release you tested in every report so the affected scope can
be established accurately.
